# Веха 3. Управляемое сокращение

**Статус:** будущая веха после получения стабильного верного источнику текста.

**Задача пользователя:** изучить материал за доступное время, выбирая нужную степень подробности.

**Как должен работать продукт:** пользователь сможет выбирать, насколько сильно сокращать материал, не теряя понимания основных мыслей.
