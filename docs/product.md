# Продуктовое видение Vidoc

Vidoc помогает изучать длинные подкасты, лекции и выступления без просмотра видео. Пользователь даёт ссылку на YouTube-видео и получает материал, который удобно читать и при необходимости сверять с источником.

## Золотой путь пользователя

1. Пользователь находит интересное видео, которое хочет изучить без длительного просмотра.
2. Передаёт ссылку на видео в Vidoc.
3. Получает расшифровку в виде хорошо отформатированного текста, который удобно читать и можно сверить с источником.
4. В сложных местах запрашивает дополнительные пояснения, чтобы разобраться в материале.

Первый сценарий ещё не выпущен. Ближайшая веха охватывает шаги 1–3; пояснения из шага 4 относятся к дальнейшему развитию. По мере появления новых возможностей этот документ обновляется и отражает актуальное состояние продукта.
