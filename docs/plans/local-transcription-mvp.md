# План: решения для MVP распознавания речи

1. Субагент добавляет ADR 0002, обновляет указатель ADR, список открытых решений и описание первой вехи по спецификации.
2. Проверить diff, локальные ссылки и отсутствие противоречий с ADR 0001.
3. Удалить рабочие спецификацию и план из итогового изменения, сохранив их в истории.
4. Отдельный субагент проводит финальное ревью по спецификации и плану из истории; устранить существенные замечания.
5. Опубликовать PR без слияния.
