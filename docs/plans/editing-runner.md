# План переноса инструмента редактуры

Спецификация: `docs/specs/editing-runner.md`.

## Задача 1: инструмент, проверки и документация

1. Перенести исходник из `artifacts/<видео>/full-video/run_edit.py` в `video-processor/scripts/edit_transcript.py`. Убрать глобальный ROOT и фиксированный заголовок; передавать пути явно из CLI. Справка фактов необязательна. Не расширять алгоритм редактуры или основной CLI.
2. Добавить автономные pytest-проверки в `video-processor/tests/test_edit_transcript.py`: два разных входа/каталога, запуск из другого cwd, факты/без фактов, заголовок, fake API, безопасное возобновление, защита входов.
3. Дополнить `video-processor/README.md` примером команды и форматом входов/результатов, AGENTS.md — правилом назначения artifacts; записать решение в лаконичный ADR 0005 и индекс.
4. Выполнить pytest и Ruff; проверить prepare-only на копии имеющегося входа во временной папке. Сохранить хеши входов и результатов до локальной миграции; удалить старый скрипт и обновить только инструкции в локальном README после проверок.

## Завершение

Контроллер проверяет diff и тесты, коммитит реализацию. Удаляет рабочую спецификацию и план из итогового diff, сохранив их в истории ветки. Отдельный субагент проверяет финальный diff по этим документам из истории и проверки. Исправить существенные замечания, опубликовать PR без слияния.

## Фокус ревью

Потеря результатов при переносе; пути, привязанные к cwd/видео; перезапись входов; повторное использование ответа для другого запроса. Повторная оценка качества модели и автоматическое уточнение по аудио в задачу не входят.
