# План реализации локальной расшифровки

Исполнение: субагент по superpowers:subagent-driven-development. Согласованный образ MVP и прямое поручение «реализуй» служат основанием для реализации.

**Цель:** рабочая `vidoc URL` с локальным распознаванием.
**Архитектура:** небольшие модули обработки и CLI внутри video_processor, без каркаса будущих слайдов. Адаптеры внешних инструментов отделены функциями для проверки ошибок и управления файлами.
**Стек:** Python >=3.11, yt-dlp, ffmpeg, faster-whisper small CPU INT8.
**Спецификация:** docs/specs/local-transcription.md.

## Ограничения

Все документы и сообщения CLI на русском. Артефакты только в корневой artifacts/. Один URL, одна модель, без удалённого распознавания. Не менять независимый открытый вопрос о качестве итогового редактированного текста.

## Критические риски

Пути с кириллицей и разделителями; YouTube-плейлист вместо видео; ошибки ffmpeg/генератора сегментов; устаревший результат после сбоя; неочищенный WAV. Каждый покрывается тестом реализации.
