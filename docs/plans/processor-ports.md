# План: модульный процессор

> Исполнение через superpowers:subagent-driven-development; одна связная задача реализации и отдельное финальное ревью.

**Цель:** отделить сценарий обработки от конкретных инструментов без изменения поведения команды.

**Архитектура:** собственные типы и Protocol-контракты, три адаптера, явная передача зависимостей из CLI. Последовательность и файловый жизненный цикл остаются в сценарии.

**Технологии:** Python 3.11+, стандартная библиотека, существующие yt-dlp/faster-whisper/ffmpeg, pytest и Ruff.

**Спецификация:** `docs/specs/processor-ports.md`.

## Общие ограничения

- Русская документация; никаких новых зависимостей.
- Не менять редактор, CLI-синтаксис, форматы результатов, модель и текущие сообщения.
- Не вводить TUI, конфигурацию, отдельный механизм сборки, PDF, динамический конвейер или абстракцию хранилища.

## Фокус ревью

Ошибка ленивого распознавания; ошибка записи второго результата; Ctrl-C; нестандартный artifacts_root; CLI --help без тяжёлых импортов. Соответствующие проверки входят в задачу 1.
