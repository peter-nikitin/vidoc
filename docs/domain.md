# Словарь предметной области

Статус: начальный словарь. Термины уточняются по мере появления проверенных продуктовых сценариев. Здесь нет классов, API и деталей хранения.

| Термин | Значение |
| --- | --- |
| Исходное видео | Одно YouTube-видео, которое пользователь хочет изучить. Оно остаётся первоисточником содержания. |
| Распознанная речь | Черновой текст, полученный из речи в видео. Может содержать ошибки распознавания и мусор устной речи; не является конечным результатом. |
| Верный источнику текст | Читаемый результат редактирования распознанной речи. Сохраняет существенные мысли, аргументы, порядок рассуждения и значимые оговорки автора без добавления новых утверждений от его имени. |
| Фрагмент | Часть текста, содержание которой можно соотнести с частью исходного видео. Границы и способ представления пока не определены. |
| Неясное место | Фрагмент, который нельзя уверенно восстановить из источника; его нельзя молча заменять правдоподобной догадкой. |
| Дополнительное объяснение | Будущий учебный материал, созданный по запросу пользователя для раскрытия мысли или примера. Не является словами автора видео. |
| Сокращённая версия | Будущий результат с выбранной пользователем степенью сокращения. Отличается от верного источнику текста уровнем отбора материала. |
| Ключевой кадр | Будущий визуальный материал из исходного видео, полезный для понимания, например слайд. |

Слово «транскрипт» без уточнения неоднозначно: им могут назвать и черновое распознавание, и готовый текст. В задачах и обсуждениях используем более точные термины из таблицы.
