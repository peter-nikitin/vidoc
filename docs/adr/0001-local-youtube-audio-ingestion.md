# ADR 0001: Скачивание аудио YouTube на локальный Mac

Дата: 2026-10-05

Статус: принято для первого этапа

## Контекст

Первый этап Vidoc должен получать исходную речь из одного YouTube-видео и создавать верный источнику читаемый текст. Для распознавания речи можно было опираться на доступные субтитры видео либо получить аудио и распознать его самостоятельно. Субтитры могут отсутствовать и не дают единого процесса оценки качества распознавания.

Пока продукт запускается только на локальном Mac пользователя. Для скачанных материалов, промежуточных файлов и результата необходимо определить место хранения без преждевременного введения удалённой инфраструктуры.

## Решение

Для получения сырой транскрипции скачиваем аудио из YouTube-видео и распознаём речь из него. Скачивать видео целиком для этой задачи не требуется. Готовые субтитры YouTube не являются основным путём получения транскрипции в первом этапе.

Обработка запускается на локальном Mac. Скачанное аудио, рабочие файлы и результат сохраняются в его локальной файловой системе. Удалённое хранилище не вводим. Конкретные каталог хранения, инструмент скачивания и модель распознавания выбираются отдельно при реализации.

## Мотивация

Один путь через аудио позволяет получать транскрипцию независимо от наличия субтитров и проверять качество распознавания на выбранных примерах. Локальная файловая система соответствует единственной среде запуска первого этапа и не добавляет потребности проектировать удалённое хранение до появления соответствующей продуктовой задачи.

## Последствия

- Получение сырой транскрипции включает скачивание аудио, его временное хранение и распознавание речи; для этого нужны доступ к видео, место на диске и время обработки.
- Нужно определить жизненный цикл скачанных и рабочих файлов при реализации, чтобы повторные запуски не оставляли ненужные данные.
- Решение о локальном хранении файлов не запрещает использовать удалённые модели для обработки текста. Выбор модели и условия передачи ей данных принимаются отдельно.
- Ограничение локальным Mac относится к первому этапу. При появлении потребности в другой среде запуска или удалённом хранилище это решение пересматривается; оно не задаёт неизменную архитектуру всего продукта.
