# Принятые решения

Здесь хранятся принятые решения, включая ответы на обязательные продуктовые и технические вопросы. Используй [шаблон](TEMPLATE.md): кратко зафиксируй проблему, выбор, его причину и значимое последствие. Не повторяй одни и те же аргументы в разных разделах.

Обязательные решения до принятия перечислены в [`../pending-decisions.md`](../pending-decisions.md). После принятия выбор и мотивация остаются в ADR, а вопрос удаляется из списка в том же изменении.

Продуктовые задачи находятся в [`../product.md`](../product.md), термины — в [`../domain.md`](../domain.md), необязательные отложенные задачи — в [`../deferred.md`](../deferred.md).
