# Архитектурные решения

Этот каталог предназначен для принятых архитектурных решений. Записываем решение, когда выбор трудно изменить, были реальные альтернативы и будущему разработчику потребуется понять причину выбора. Указываем контекст, альтернативы, выбранный вариант, последствия и дату.

Продуктовые задачи находятся в [`../product.md`](../product.md), термины — в [`../domain.md`](../domain.md), отложенные вопросы — в [`../deferred.md`](../deferred.md). Пока новых архитектурных решений по первому этапу нет.
