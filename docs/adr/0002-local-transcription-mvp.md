# ADR 0002: Локальный MVP распознавания речи

Дата: 2026-10-25

Статус: принято для MVP

## Контекст

Первый проверяемый результат — получение распознанной речи из одного YouTube-видео. MVP запускается на Mac пользователя.

## Решение

Запускаем обработку командой в терминале: на входе только ссылка на видео. По [ADR 0001](0001-local-youtube-video-ingestion.md) скачиваем полный видеофайл и извлекаем аудио. Речь распознаём локально на Mac; сравнение с удалёнными сервисами в MVP не входит.

Артефакты сохраняем в `artifacts/` в корне проекта, исключённой из Git. Для каждого видео создаём подпапку `<безопасное название>-<YouTube ID>/`: имя выводим из названия видео, ID различает одинаковые названия. В ней сохраняем видеофайл, сырую расшифровку с временными отметками, ссылку и название источника. Редактирование распознанной речи в читаемый текст — следующий шаг первой вехи.

## Почему

Локальный сквозной запуск позволяет проверить получение речи на своих видео в согласованных границах MVP. Общая папка артефактов избавляет пользователя от выбора места сохранения при каждом запуске и исключает результаты обработки из коммитов.

## Последствия

Конкретную локальную модель ещё предстоит выбрать и проверить на пользовательском видео. Сырая расшифровка может содержать речевой мусор и ошибки распознавания; она не завершает первую продуктовую веху.
