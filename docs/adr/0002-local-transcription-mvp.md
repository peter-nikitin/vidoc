# ADR 0002: Локальный MVP распознавания речи

Дата: 2026-10-25

Статус: принято для MVP

## Контекст

Первый проверяемый результат — получение распознанной речи из одного YouTube-видео. MVP запускается на Mac пользователя.

## Решение

Запускаем обработку командой в терминале: на входе ссылка на видео и папка результата. По [ADR 0001](0001-local-youtube-video-ingestion.md) скачиваем полный видеофайл и извлекаем аудио. Речь распознаём локально на Mac; сравнение с удалёнными сервисами в MVP не входит.

В папке результата сохраняем видеофайл, сырую расшифровку с временными отметками, ссылку и название источника. Редактирование распознанной речи в читаемый текст — следующий шаг первой вехи.

## Почему

Локальный сквозной запуск позволяет проверить получение речи на своих видео в согласованных границах MVP.

## Последствия

Конкретную локальную модель ещё предстоит выбрать и проверить на пользовательском видео. Сырая расшифровка может содержать речевой мусор и ошибки распознавания; она не завершает первую продуктовую веху.
