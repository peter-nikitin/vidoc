# ADR 0001: Скачивание YouTube-видео на локальный Mac

Дата: 2026-10-05

Статус: принято для первого этапа

## Контекст

Нужно получить текст из YouTube-видео. Субтитров может не быть, поэтому получение текста не должно от них зависеть.

## Решение

Скачиваем полный видеофайл через [`yt-dlp`](https://github.com/yt-dlp/yt-dlp/blob/master/README.md), извлекаем из него аудио через [`ffmpeg`](https://ffmpeg.org/ffmpeg.html), затем распознаём речь. Первый этап запускается на локальном Mac: скачанный файл, рабочие файлы и результат хранятся в его файловой системе. Удалённое хранилище не используем.

## Почему

Полный файл сохраняет видеоряд для будущего извлечения ключевых кадров.

## Последствия

Полный файл занимает место на диске; при реализации нужен порядок удаления рабочих файлов.
