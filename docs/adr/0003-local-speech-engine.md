# ADR 0003: Локальное распознавание через faster-whisper

Дата: 2026-10-25

Статус: принято для MVP; качество на пользовательских видео требует проверки

## Контекст

[Локальному MVP](0002-local-transcription-mvp.md) нужен конкретный движок распознавания с временными отметками.

## Решение

Используем [faster-whisper](https://github.com/SYSTRAN/faster-whisper#usage) с многоязычной моделью Whisper `small`, CPU и INT8. Модель загружается при первом запуске в `artifacts/.models/`; речь обрабатывается локально. Сохраняем текст сегментов с началом и концом в `transcript.txt`, сведения об источнике, языке и модели — в `source.json`.

## Почему

Движок уже был предусмотрен зависимостями каркаса, поддерживает локальный CPU и временные отметки. `small` — стартовый компромисс между размером и качеством для проверки цепочки.

## Последствия

Первый запуск требует сети для весов. CPU определяет скорость обработки; выбор модели не доказывает качество расшифровки. Результат остаётся сырым распознаванием.
