# Vidoc

Vidoc помогает изучать длинные подкасты, лекции и выступления без просмотра видео целиком. На первом этапе пользователь передаёт ссылку на одно YouTube-видео и получает один читаемый текст, верный содержанию источника.

Это не дословная автоматическая расшифровка: речь нужно очистить от слов-паразитов, повторов и оговорок, восстановить пунктуацию и разбить на смысловые части. При этом нельзя добавлять утверждения от имени автора или терять существенные мысли. Спорные фрагменты должны оставаться проверяемыми по исходному видео; способ проверки пока не определён.

Первая версия ограничена получением такого текста. Ключевые кадры, управление степенью сокращения и дополнительные учебные объяснения относятся к следующим этапам. Локальные и удалённые модели — варианты реализации, которые предстоит сравнить по качеству результата.
